# Генератор описаний вакансий

## Проблема

Подготовка вакансий занимает время: нужно понятно описать задачи, требования и условия работы, передать стиль компании и адаптировать текст под площадку. Сервис помогает быстро создавать понятные и привлекательные описания вакансий.

## Пользователь

HR-специалисты, рекрутеры, руководители команд и владельцы небольших компаний, которые самостоятельно ищут сотрудников.

## Основная функция

Сервис создаёт описание вакансии на основе информации пользователя:

1. Пользователь вводит название роли, задачи, требования, условия работы и стиль компании.
2. Выбирает площадку для публикации: HH, Telegram или сайт компании.
3. Сервис передаёт данные языковой модели через API и генерирует текст с учётом выбранной площадки и стиля.
4. Пользователь проверяет, при необходимости редактирует и копирует результат для публикации.

При генерации используются предоставленные сведения: сервис не должен придумывать зарплату, льготы или другие условия работы.

## Формат результата

Готовый текст вакансии для проверки и публикации:

- **Для HH** — подробное описание с разделами «Задачи», «Требования» и «Условия».
- **Для Telegram** — компактный пост с основной информацией.
- **Для сайта компании** — структурированный текст для раздела «Карьера».

## Минимальный функционал (MVP)

- Форма ввода сведений о вакансии.
- Выбор площадки для публикации.
- Выбор стиля текста: деловой, нейтральный или дружелюбный.
- Генерация описания вакансии.
- Редактирование, повторная генерация и копирование результата.

В дальнейшем планируется добавить историю вакансий, сохранение шаблонов компании, генерацию нескольких вариантов и проверку текста на непонятные или противоречивые формулировки.

## Технологии

Планируемый стек:

- **Python** — основной язык программирования.
- **Flask** — серверная часть приложения и обработка запросов.
- **HTML/CSS** — структура и оформление веб-интерфейса.
- **JavaScript** — отправка данных формы и отображение результата.
- **API языковой модели** — генерация описаний вакансий.
- **JSON** — формат обмена данными между интерфейсом и сервером.
- **Обычный текст** — формат готового описания для редактирования и копирования.
